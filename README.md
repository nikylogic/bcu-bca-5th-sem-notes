### 1. DCCA513: Software Engineering
* **Exam Date:** 02-12-2026 (Wednesday)
* **Coverage:**
  * **Unit I:** Software Crisis, SDLC Framework, Waterfall, Prototyping, Spiral, Incremental, and Agile (Scrum).
  * **Unit II:** Requirement Engineering, Feasibility Analysis, SRS (IEEE 830), Cohesion & Coupling, DFD Levels, and UML Diagrams.
  * **Unit III:** V-Model, Unit/Integration/System Testing, Black-Box (BVA, Equivalence Partitioning) vs White-Box (Basis Path, Cyclomatic Complexity).
  * **Unit IV:** 4 Maintenance Types, Reverse/Re-engineering, SQA, Basic COCOMO Model, and RMMM Risk Planning.
* [📥 Download Software Engineering PDF](pdfs/DCCA513_Software_Engineering_Solved_Question_Bank_BCU_BCA_5th_Sem.pdf)

### 2. DCCA511: Web Programming
* **Exam Date:** 26-12-2026 (Saturday)
* **Coverage:**
  * HTML5 semantic tags, CSS3 Box Model, Flexbox, and Grid layouts.
  * JavaScript DOM manipulation, ES6 features, event handling, and form validation.
  * PHP server-side scripting, superglobals (`$_GET`, `$_POST`, `$_SESSION`), MySQL database connectivity, and XML/JSON parsers.
* [📥 Download Web Programming PDF](pdfs/DCCA511_Web_Programming_Solved_Question_Bank_BCU_BCA_5th_Sem.pdf)

### 3. DCCA512: Data Analytics
* **Exam Date:** 29-12-2026 (Tuesday)
* **Coverage:**
  * Descriptive vs Inferential Statistics, Mean/Median/Mode, Variance, and Standard Deviation.
  * Data pre-processing, handling missing values, outlier detection, and data visualization (Matplotlib/Seaborn).
  * Supervised vs Unsupervised Machine Learning, Linear/Logistic Regression, Decision Trees, K-Means Clustering, and Model Evaluation metrics (Confusion Matrix, Precision, Recall, F1-Score).
* [📥 Download Data Analytics PDF](pdfs/DCCA512_Data_Analytics_Solved_Question_Bank_BCU_BCA_5th_Sem.pdf)

### 4. DCCA514: Cryptography and Network Security
* **Exam Date:** 31-12-2026 (Thursday)
* **Coverage:**
  * **Unit I:** OSI Security Architecture, Security Attacks (Active vs Passive), Classical Encryption (Caesar, Playfair, Hill, Vigenère, Rail Fence).
  * **Unit II:** Modern Symmetric Ciphers (DES round structure, 3DES, AES 128-bit state matrix, Block Cipher Modes of Operation: ECB, CBC, CFB, OFB, CTR).
  * **Unit III:** Asymmetric Key Cryptography, Number Theory (Modular Arithmetic, Euler's Totient, Fermat's Little Theorem), RSA Algorithm with full numericals, Diffie-Hellman Key Exchange, and Man-in-the-Middle Attack.
  * **Unit IV:** Cryptographic Hash Functions (SHA-512, MD5), HMAC, Digital Signatures (DSS), Kerberos Authentication, X.509 Certificates, IPsec (AH & ESP), SSL/TLS Protocol Stack, and Firewalls.
* [📥 Download Cryptography & Network Security PDF](pdfs/DCCA514_Cryptography_Network_Security_Solved_Question_Bank_BCU_BCA_5th_Sem.pdf)
